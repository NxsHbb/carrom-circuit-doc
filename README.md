# Carrom Circuit — published documentation

The buyer documentation for the Carrom Circuit CodeCanyon item, published here
so that it is reachable without downloading the item. Open `index.html`, or the
GitHub Pages URL for this repository.

## This directory is generated

Do not edit anything here. The documentation source lives in the item's own
(private) repository as `docs/index.html`, and this tree is rebuilt from it by
`tool/build_public_docs.py`. An edit made here is lost on the next publish, and
in the meantime the two copies disagree — which is worse than either of them
being wrong, because nothing says which one a reader should believe.

To change the documentation: edit it in the source repository, re-run the
build, and copy the result over this tree.

## Publishing

GitHub Pages, from this repository's default branch at the root:

1. Push this tree to the repository root.
2. **Settings → Pages → Build and deployment → Deploy from a branch**, branch
   `main`, folder `/ (root)`.
3. The site appears at `https://<user>.github.io/<repo>/` within a minute or
   two.

The repository must be **public**: Pages does not serve a private repository on
a free plan. Nothing here is private — it is the same documentation that ships
inside the purchased item.
